# Shush 🤫

> **shush** /ʃʊʃ/ _verb_  
> To urge or request silence.

Shush is a quiet little writing space that feels like a sheet of paper sitting in a browser tab. There are no folders,
accounts, or templates, just a single open page ready for text.

The page is a continuous roll sized to A4 paper with one-inch margins. It replicates the classic pica typewriter pitch:
12pt IBM Plex Mono on 18pt leading (1.5 line spacing). Each character is 7.2pt wide (10 characters per inch),
and a quarter-inch line height. That gives you an exact grid of 62 characters per line and 38 lines per page, so
what you see on the screen matches what lands on printed paper.

Writing and reading are two distinct modes toggled with `Esc`, each designed for a different kind of attention. Writing
involves working closely with characters, spacing, and line breaks, so edit mode keeps that structure visible and
anchors the active paragraph. Reading is about moving smoothly down the page, so read mode stays distraction-free.

Your text stays in your browser's local storage and never touches a server. Notes can be exported as plain text files
with `Ctrl+S` (or `Cmd+S` on macOS) and imported by dragging a file onto the page.

There are no external dependencies, no build steps, and no network requests. The project is complete by design, static,
and hosted on GitHub Pages at [/shh](https://noid.dev/shh).
